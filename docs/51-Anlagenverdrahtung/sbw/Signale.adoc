`sw` an Pin 1 (außen)
|Das Blocksignal `Sbk1` ist derzeit noch nicht vorhanden. +
Der Anschluss wird nur für die Vorsignale `sbk1[Px]` verwendet. Sie sind in der Anlagenkonfiguration nicht enthalten, sondern über einen Verteiler direkt mit `Sbk1` verbunden. Der `+`-Anschluss wird jeweils vom Hauptsignal `Px` versorgt, so dass die Vorsignale `dunkel` sind, wenn das Hauptsignal `HP00` oder `SH1` zeigt.
