= Implementierung des Web-UI

. Technologie
+
Das Web UI wird mit Vaadin Flow (serverseitiges Java-UI) erstellt.
Die Views liegen je Service im Paket `webui` und sind als `@Route` mit dem gemeinsamen Layout `MainLayout` aufgebaut.
+
Das Vorgängersystem auf Basis von JSF/PrimeFaces wurde vollständig abgelöst; die Migrationsunterlagen stehen in `docs/11-Agentische-migration-faces-vaadin`.

. Gemeinsame Bausteine (`v5t11-vaadincommon`)
+
|===
|Klasse|Aufgabe

|`V5t11VaadinServlet`
|Vaadin-Servlet unter `/ui/*`; `@Route`-Werte sind relativ zu diesem Präfix anzugeben, z. B. `@Route("system-status")`.

|`MainLayout`, `VaadinNavigationMenu`
|Gemeinsames Layout mit dem föderierten Navigationsmenü.

|`NavigationPresenter`
|Sammelt die Menüeinträge aller Services (Eigeneinträge und per Messaging empfangene Heartbeats) und benachrichtigt die Menüs über `addMenuChangeListener`.

|`HomeView`, `RootRedirectServlet`
|Startseite bzw. Weiterleitung von `/`.
|===

. Besonderheiten
+
* Das Stellwerk-Gleisbild wird je Zelle in einem eigenen `<canvas>`-Element gezeichnet (`StellwerkCanvas`). Die Zeichenbefehle erzeugt `StellwerkDrawCommandBuilder`, gezeichnet wird mit `stellwerk-draw.js`.
* Änderungen an Fachobjekten (`@Changed`-CDI-Events) werden über je einen `VaadinChangePushBroadcaster` pro Service an die Views verteilt, die sich per `UI.access(...)` gezielt aktualisieren.
* Eigene Styles (z. B. Toggle-Buttons und Stellungsbuttons) liegen im Theme `v5t11` in `v5t11-vaadincommon`.
